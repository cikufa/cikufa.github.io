# Shekoufeh Sadeghi — Personal Academic Website

Static GitHub Pages website modeled after the structure and visual language of https://kartikeya13.github.io/.

## Files
- `index.html` — complete single-page website with embedded CSS
- `assets/profile.jpeg` — profile photo
- `assets/Shekoufeh_Sadeghi_CV.pdf` — CV linked from the site
- `assets/resume.tex` — LaTeX source for the linked CV

## Publish
This repository is configured as the GitHub Pages user site for `cikufa`, so it is served at `https://cikufa.github.io/` from the default branch root.
